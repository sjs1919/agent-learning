## 一、功能模块清单

系统包含六大核心功能模块：

- 注册用户管理
- 商品SKU与库存管理
- 订单管理
- 系统用户与权限管理
- 多语言支持（面向海外市场的国际化支持）
- 多货币管理（汇率管理与人民币金额计算）

### 1.1 注册用户管理模块

#### 功能概述

管理商城注册用户的全生命周期，包括用户状态管理、信息维护和密码重置等功能。

#### 功能清单

| 功能名称   | 功能描述             | 核心实现要点         |
| ------ | ---------------- | -------------- |
| 用户列表查询 | 支持搜索、筛选、分页展示用户列表 | 多条件动态查询、分页缓存优化 |
| 用户详情查看 | 查看用户完整信息及历史操作记录  | 关联查询订单、售后等业务数据 |
| 用户状态管理 | 启用/激活/禁用用户账户     | 状态机模式、状态变更日志记录 |
| 用户密码重置 | 管理员重置用户密码        | 临时密码生成、邮件通知机制  |
| 用户信息编辑 | 修改用户基本信息         | 数据校验、变更审计日志    |

#### 技术要点

- **状态流转**：待激活 → 已激活 ↔ 已禁用
- **数据表**：users表，status字段控制用户状态
- **安全机制**：密码加密存储（bcrypt）、临时密码有效期控制

***

### 1.2 商品SKU与库存管理模块

#### 功能概述

实现商品分类、商品信息、SKU规格和库存的全流程管理，支持树形分类结构和多规格商品管理。

#### 功能清单

| 功能名称    | 功能描述              | 核心实现要点               |
| ------- | ----------------- | -------------------- |
| 商品分类管理  | 树形结构分类的增删改查和排序    | 父ID+层级+路径组合方案、递归查询优化 |
| 商品列表管理  | 商品的创建、编辑、删除、查询    | 分类关联、图片上传、状态流转       |
| SKU规格管理 | 商品规格（颜色、尺寸、内存等）管理 | JSON存储规格属性、动态规格模板    |
| 库存数量管理  | SKU级别库存增减和查询      | 库存预占机制、并发锁控制         |
| 库存预警设置  | 设置库存阈值并触发预警通知     | 定时任务扫描、消息队列通知        |
| 库存变动记录  | 记录所有库存变更历史        | 审计日志、变动类型分类          |

#### 技术要点

- **树形分类**：categories表采用parent\_id + level + path组合，支持无限级分类
- **商品图片**：main\_image主图 + images多图数组，支持OSS存储
- **SKU规格**：specs字段使用JSON存储，如`{"color":"黑色","memory":"256GB"}`
- **库存并发**：乐观锁/悲观锁机制防止超卖
- **数据表**：categories、products、skus

***

### 1.3 订单管理模块

#### 功能概述

管理订单全生命周期，从创建、支付、发货到完成，支持多语言多币种订单和售后处理。

#### 功能清单

| 功能名称   | 功能描述         | 核心实现要点           |
| ------ | ------------ | ---------------- |
| 订单列表查询 | 多条件筛选查询订单列表  | 动态查询、索引优化、分页展示   |
| 订单详情查看 | 查看订单完整信息和明细  | 关联查询用户、商品、SKU信息  |
| 订单发货处理 | 填写物流信息并确认发货  | 物流信息存储、状态流转、通知推送 |
| 订单状态流转 | 订单状态变更管理     | 状态机模式、状态变更日志     |
| 售后申请处理 | 退款/退货申请审核和处理 | 售后工单、退款流程、库存回滚   |
| 物流信息管理 | 物流公司、运单号管理   | 物流API对接、轨迹查询     |

#### 技术要点

- **订单状态机**：待付款 → 待发货 → 待收货 → 已完成（支持取消、售后分支）
- **多语言支持**：user\_language字段记录下单语言，product\_name快照存储对应语言版本
- **多币种处理**：currency + exchange\_rate + cny\_amount实现汇率快照机制
- **订单明细**：order\_items表存储商品快照，支持历史数据追溯
- **金额计算**：明细小计 → 订单总额 → 人民币金额（汇率换算）
- **数据表**：orders、order\_items

***

### 1.4 系统用户与权限管理模块

#### 功能概述

基于RBAC模型实现系统用户的权限控制，支持角色管理、权限分配和操作日志记录。

#### 功能清单

| 功能名称   | 功能描述            | 核心实现要点         |
| ------ | --------------- | -------------- |
| 系统用户管理 | 后台用户的增删改查       | 用户创建、角色分配、状态管理 |
| 角色管理   | 角色的创建、编辑、删除     | 角色编码唯一性、权限关联   |
| 权限分配   | 为角色分配菜单/按钮/接口权限 | 权限树形结构、批量分配    |
| 操作日志记录 | 记录用户操作行为        | AOP切面日志、异步写入   |

#### 技术要点

- **RBAC模型**：用户 → 角色 → 权限 三层关联
- **权限类型**：菜单权限（前端路由）、按钮权限（页面元素）、接口权限（后端API）
- **权限树**：permissions表parent\_id支持树形结构
- **数据表**：admin\_users、roles、permissions、user\_roles、role\_permissions

***

### 1.5 多语言支持模块

#### 功能概述

面向海外市场的国际化支持，包含后台界面多语言、商品多语言维护和用户语言追踪。

#### 功能清单

| 功能名称    | 功能描述             | 核心实现要点          |
| ------- | ---------------- | --------------- |
| 语言包管理   | 语言包的增删改查、启用/禁用   | 语言代码标准化、翻译键值对管理 |
| 界面多语言配置 | 菜单、按钮、提示信息多语言    | i18n框架、动态语言切换   |
| 商品多语言维护 | 商品名称、描述多语言版本     | 商品翻译表、语言版本关联    |
| 商品分类多语言 | 分类名称多语言支持        | 分类翻译表、级联翻译      |
| 用户语言追踪  | 记录用户使用的语言版本      | 订单语言字段、用户偏好存储   |
| 翻译导入导出  | CSV/JSON格式批量导入导出 | 文件解析、数据校验、批量更新  |
| 翻译缺失检测  | 检测未翻译的内容         | 完成度统计、缺失标记      |

#### 技术要点

- **支持语言**：zh-CN（默认）、en-US、ru-RU、ja-JP、ko-KR、es-ES
- **语言切换**：无刷新切换，Accept-Language请求头支持
- **商品翻译**：product\_translations表存储多语言版本
- **语言检测**：浏览器语言自动检测，用户偏好持久化

### 1.6 多货币管理模块

#### 功能概述

支持海外市场的多货币交易，包含货币维护、汇率管理和订单人民币金额计算。

#### 功能清单

| 功能名称   | 功能描述           | 核心实现要点          |
| ------ | -------------- | --------------- |
| 多货币维护  | 货币的添加、编辑、禁用    | 货币代码、符号、小数位数管理  |
| 汇率管理   | 货币对汇率的CRUD操作   | 与CNY汇率对应、汇率来源记录 |
| 汇率自动更新 | 定时调用第三方API更新汇率 | 定时任务、API对接、异常处理 |
| 订单金额计算 | 非人民币订单的人民币金额计算 | 汇率快照、实时计算       |
| 汇率快照   | 订单创建时永久保存汇率    | 历史数据准确性保障       |

#### 技术要点

- **汇率快照**：订单创建时记录exchange\_rate，永久保存不受后续变动影响
- **金额计算**：cny\_amount = total\_amount × exchange\_rate
- **人民币订单**：currency=CNY, exchange\_rate=1, cny\_amount=total\_amount
- **数据表**：currencies（货币表）、exchange\_rates（汇率表）

## 二、核心业务流程

### 2.1 用户注册→下单流程

```
用户注册(待激活) → 邮箱激活 → 浏览商品 → 加入购物车 → 创建订单(记录语言/币种) 
→ 支付 → 发货 → 确认收货 → 完成
```

### 2.2 商品上架→销售流程

```
创建分类 → 创建商品 → 创建SKU → 设置库存 → 上架 → 用户下单 → 库存扣减 → 发货
```

### 2.3 权限分配流程

```
创建权限(菜单/按钮/接口) → 创建角色 → 分配权限给角色 → 创建用户 → 分配角色给用户
```

## 三、技术架构要点

### 3.1 权限模型

- 采用RBAC（基于角色的访问控制）模型
- 支持菜单、按钮、接口三级权限控制
- 权限树形结构支持无限级嵌套

### 3.2 多语言架构

- 后台界面：i18n国际化框架
- 业务数据：翻译表关联方案
- API支持：Accept-Language请求头

### 3.3 多货币架构

- 汇率快照机制保证历史数据准确
- 订单层面统一换算，明细保持原币种
- 定时任务自动更新汇率

### 3.4 数据一致性

- 库存并发控制（乐观锁/悲观锁）
- 订单状态机模式
- 数据快照机制（商品信息、汇率）
