## Key Experience Summary

### Success Points
1. Framework source must be prepared first: Avoid AI hallucinations
2. Debug one API first: Create template, batch reuse
3. Multiple rounds of correction: AI-generated content needs manual review
4. Context is important: Project and team context significantly improve code quality

### Common Mistakes
1. Let AI generate code directly without providing framework source
2. Expect AI to generate perfect code in one go
3. Skip code review process
4. Skip testing before QA submission
