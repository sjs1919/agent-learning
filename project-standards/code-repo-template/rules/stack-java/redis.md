# Redis 规则（Java/Spring）

## 使用场景

- 缓存：查询热点数据（余额/费率/配置），带过期时间，防穿透
- 分布式锁：跨服务互斥（如同一地址并发提现 Nonce 分配），用 Redisson 或 SETNX + 过期
- 幂等：入账/提现请求幂等键，防重复处理

## Key 规范

- 格式：`服务名:业务域:业务键`（如 `account:addr:0x...`）
- 统一带 TTL；业务锁设合理过期时间 + 持有者标识防误删

## 数据一致性

- 缓存与 DB 最终一致：写操作先 DB 后删缓存（Cache Aside）
- **严禁把 Redis 当唯一数据源存储资金账务**（账务必须落 MySQL）
